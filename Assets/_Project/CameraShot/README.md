# CameraShot

## 时间轴与曲线

在动作编辑器添加 CameraShot 区间事件，指定 Profile，拖动轨道两端控制镜头总长度。
Profile 的“进入 / 退出权重”曲线横轴为整个区间的归一化进度，纵轴为镜头权重：0 是正常游戏相机，1 是目标构图。
默认关键点为 (0, 0)、(0.2, 1)、(0.75, 1)、(1, 0)。进入、保持、退出全部发生在区间内。
拉长轨道会同比拉长全过程；动作减速或顿帧时镜头进度也跟随动画。反向拖动预览没有累计时间误差。
轨道结束或动作被打断时立即释放本镜头，不额外添加秒数退出段。要平顺结束，请将曲线末点设为 0。

PositionTravel × MotionCurve 控制目标相机自身的位移，与进入 / 退出权重独立。
普通镜头作为混合基准持续更新，震屏在镜头构图之后叠加。

## 退出位置

权重曲线最后一个最高点之后进入退出段。FreeLook 在合法 X/Y 轨道范围中搜索，再逐步细化，选择位移、转角和画面构图综合变化较小的接续位置；旧轨道也作为候选。
位移按观察距离归一化，避免旧算法几乎忽略相机位移。搜索是有限采样，不保证数学上的全局最小值。
接续速度仍由轨道权重曲线决定，不使用额外秒数。运行时保留新轨道角度，解锁后不回到进入前的旧角度。
编辑窗口和 Game 预览使用非激活副本求解，不修改场景中真实相机的轴值。有其他镜头重叠时优先交回下层镜头。

## 编辑与保存

在 CameraShot 事件面板点击“编辑镜头 / 实时预览”。配置字段及 Scene 手柄修改自动保存，支持 Undo。
窗口按项目和 Profile 记住玩家、目标、源相机、时间轴联动、手柄模式及手动预览进度。
场景对象需要所在场景已加载；临时动作预览角色会在动作预览重新建立后自动绑定。
在窗口切换 Profile 会同步修改当前轨道事件的 Profile 引用。

时间轴联动时直接使用动作编辑器进度；独立预览提供 0–1 进度滑块和循环播放。
窗口显示当前权重。权重为 0 时看到的是游戏相机，移动目标手柄不会改变该帧画面。
“在 Scene 中定位目标相机手柄”定位编辑手柄；W/E 切换移动和旋转。
“采用游戏相机构图”将源相机当前姿态保存为玩家固定构图；“转换为玩家固定构图”仅在其他构图模式下显示。
两种转换都会清空 PositionTravel，可以 Undo。未指定源相机时不能采用游戏相机构图。

## 构图模式

Actor Start Pose：目标位置和角度相对于事件开始时玩家的水平朝向，位置跟随玩家，方向不随之后转身改变。
Game Camera Relative：在正常游戏相机当前坐标系中叠加位置和角度。
Actor Anchored：分别选择位置和注视锚点，支持玩家、目标和中点。

Main_Nodachi 的 FreeLook 已安装 CinemachineCameraShotExtension。事件 Channel 应与扩展一致。
勾选事件 PreviewCamera 可同时在 Game 窗口预览；独立编辑窗口不要求开启此选项。
URP 预览沿用源相机配置，但不包含相机堆栈里的独立 UI 相机。

## 代码调用

CameraShotRuntime.Begin 创建句柄，SetProgress(handle, progress) 启用上述曲线驱动，Release(handle) 结束。
动作轨道使用曲线驱动。未调用 SetProgress 的独立定时调用仍保留旧的 BlendIn / BlendOut 行为，供既有代码使用；这些秒数字段不出现在轨道配置界面。
