# CameraShot 编辑与预览

在动作编辑器添加 CameraShot 区间事件，指定 Profile，双击镜头区间或点击「编辑镜头 / 实时预览」打开窗口。

## 摆机位

- 「编辑目标构图」直接显示目标镜头，忽略融合权重，入场第一帧也可以摆机位。
- 「预览最终效果」显示基础相机、进入融合、运镜和退出的合成结果。
- 「采用当前 Scene 视角」将透视 Scene 视图的位置、朝向、FOV 转换为当前镜头参考空间。保留已有运镜；关键帧模式只记录当前时间的关键帧。
- 预览画面内：右键观察，按住右键用 WASD / QE 移动；中键平移；滚轮推拉；Alt + 左键围绕角色上身旋转；Shift 加速。FOV 在配置里单独调整。
- 开启自动看向玩家 / 轨道限制时，右键改为环绕角色，朝向仍遵守约束。自由朝向需要明确关闭对应约束。
- Scene 移动 / 旋转手柄仍可使用。操作支持 Undo，Profile 自动保存。

## 原地动作也能运镜

「动作与镜头」使用动作编辑器播放进度；角色按原来的动画和动作位移配置运动。原地攻击不会被添加额外位移。
「仅镜头（冻结角色）」暂停动作编辑器，在当前角色姿势上独立播放镜头，可修改预览时长。
两个模式都支持进入、运动和退出。相机推近、环绕等不依赖角色移动。

预览使用非激活的 FreeLook 副本，绑定预览角色，并以 60 Hz 时间步推进基础跟随、镜头缓冲与融合。后退 / 跳帧从起始状态重放，重复播放不会累积历史状态。源 FreeLook 的轴值不会由窗口预览修改。
「预览绑定」中可指定基础 FreeLook；未找到时会明确提示，此时不能验证完整基础跟随。
当前适配 Cinemachine 2.10.7：手动重放会清除仅属于预览副本的帧调度缓存，保留阻尼历史；不会清除场景相机的缓存。升级 Cinemachine 后需要重新验证此适配。

## 关键帧

原 PositionTravel × MotionCurve 保持可用。「将当前运镜复制为起止关键帧」显式启用关键帧，复制起止位置、角度与 FOV；原曲线数据保留。
注意：起止关键帧使用平滑插值，不保证复制任意原曲线的中间节奏。需要精确复现时增加中间关键帧，或在运镜面板关闭关键帧模式恢复原数据。
点击关键帧定位时间，摆机位自动记录当前时间，也可添加 / 删除关键帧。关键帧位置、角度相对于所选构图参考空间。
「采用游戏相机构图 / 转换为玩家固定构图」是显式转换，会停用关键帧并清空 PositionTravel，支持 Undo；关键帧列表仍保留。

## 本片段过渡

旧资产默认兼容原规则，不自动改写。
事件面板 / 镜头窗口可显式启用「使用片段内进入 / 退出」：

- 进入与退出占比随动作时间推进，总和不超过整个片段。
- 时间轴蓝色区域为进入，橙色区域为退出，拖动顶部小手柄可按动作帧调整。
- 正常结束（退出占比大于零）在片段内返回持续更新的基础游戏镜头，不追加退出尾段。
- 提前中断从当前镜头状态退出，时长使用 Profile.BlendOut。
- 新接管镜头从此前输出接入；游戏相机相对模式作为轻量修饰，始终以当前基础游戏镜头为基准。
- 片段进入 / 退出独立于运镜关键帧。

未启用时保留 WeightCurve、ReturnStart 和旧的 FreeLook 接续求解。只有曲线末端权重小于 ReturnStart 处权重时才启用区间回程；否则事件结束后使用 BlendOut 退出。
BlendIn 用于非时间轴调用；动作事件正常进入由曲线或片段进入占比控制。

## 验证边界

窗口能够预览静态场景障碍、基础相机跟随与当前镜头。运行时输入、未录制的敌人运动、跨动作中断及多镜头竞争仍需 Play 模式验证；窗口不是整个游戏的模拟器。
旧事件的 PreviewCamera 是原有 Game 窗口预览开关，独立镜头窗口无需开启。Game 窗口原预览链路不等同于窗口的固定时间步重放。
URP 预览继承源相机渲染设置，不包含相机堆栈里的独立 UI 相机。
菜单 Tools / Camera / Validate Camera Shot 执行隔离验证，包含旧行为、原地运镜、基础跟随、跳帧一致性和片段过渡。
