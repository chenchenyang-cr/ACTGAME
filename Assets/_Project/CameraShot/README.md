# CameraShot 轨道机位节点

在动作编辑器添加 CameraShot 点事件。时间轴上与粒子事件一样只有一个可拖动的触发节点；选中或双击节点，在现有 CombatInspector 中编辑机位和时间参数。

一个节点包含多个候选机位，触发时选择距当前相机最近的一个，本次播放保持该选择。

## 机位

- 水平角度为 0–360°：0° 在玩家后方、90° 在右侧、180° 在前方、270° 在左侧。仅决定方向，旧机位数据在编辑器中自动显示为对应角度。
- 镜头高度以玩家根节点为基准，自动限制到现有 FreeLook 轨道允许的高度。
- 镜头距离、Follow、LookAt、FOV、跟随阻尼和已有碰撞扩展取自基础 FreeLook。CameraShot 只控制机位轨道，视野伸缩由 CameraShake 控制。机位随玩家位置和朝向更新。
- 转入、保持和转出通过 FreeLook 轨道轴采样，整个过渡都遵守现有轨道约束。

## 时间和曲线

在 CombatInspector 设置「回到原镜头位置」开关，默认开启。开启时设置转入秒数和曲线、保持秒数、转出秒数和曲线，节点总时长为三段之和。关闭时不执行回程，总时长只计算转入和保持；结束后从最终机位继续普通相机操作。曲线 X 为 0–1 的过渡进度，Y 为 0–1 的完成程度。

节点由触发帧启动，按动作经过的秒数推进；正常播完后停止接管，不会在后续帧重复触发。开启回程时，动作提前中断会从当前轨道位置按转出曲线退出，中断转出按实际时间推进。关闭回程时，中断会从当前机位直接交回相机操作。动作新一轮播放可重新触发节点。

时间轴只编辑触发时刻。CameraShot 不再使用区间条、区间边界或转入转出拖动把手。

「不受顿帧影响」默认关闭，保持随动作时间推进。开启后，转入、保持和转出按实际时间独立推进，不受角色和全局顿帧影响；动作中断仍按原有退出规则处理。编辑器拖动预览继续使用时间轴时间。

## 预览

节点内可逐个查看机位，或预览实际选择与过渡。通过动作编辑器播放、拖动时间轴，角色按原动画、Root Motion 和动作位移配置运动，相机按固定时间步重放。前拖沿用已计算的状态，倒拖会重置并重放；预览不修改原 FreeLook 的轴值。

开启轨道预览和「同步游戏视图」后，将同一镜头结果同步到 Game view。关闭轨道预览仍可在 CombatInspector 中查看镜头。参数支持 Undo，并自动保存。

现有 ParryCameraShot 包含后方左、右两个候选机位，已转为点触发。旧自由位置、旋转、位移曲线、关键帧和独立编辑窗口已移除。

Tools / Camera / Validate Camera Shot 使用真实 Cinemachine FreeLook 检查轨道约束、最近机位选择、过渡曲线、倒拖、输入接管和事件清理；结果写入 Temp/CameraShotValidation.txt。实际连续攻击、中断、慢动作和墙边运镜手感仍需 Play 模式验收。
