# 横向十字闪光 CrossFlare

横线与竖线以固定亮芯宽度直接交叉，交点自然叠亮。两侧带宽范围浅蓝柔光，两端渐隐。从中心向两侧展开后整体淡出。

## 使用

- 预制体：`Assets/_Project/VFX/Effects/Prefabs/CrossFlare/CrossFlare.prefab`
- 橙红色版本：`Assets/_Project/VFX/Effects/Prefabs/CrossFlare/CrossFlare_OrangeRed.prefab`；使用独立橙红色材质，控制器的 Core Color / Glow Color 与材质一致。
- 独立预览场景：`Assets/_Project/VFX/Effects/Scenes/CrossFlare_Preview.unity`，进入 Play 模式自动循环。
- 将预制体拖入任意 URP 场景，启用对象自动播放。可用 `CrossFlareController.Play()` 重播、`Stop()` 清除，适合对象池复用。
- 编辑模式选中实例或打开 Prefab 模式，在组件 Inspector 中使用“播放一次”“循环预览”或“定格时间”或“定格峰值”。

## 默认参数

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| Horizontal Length | 18 | 横线全长，世界单位 |
| Vertical Length | 9 | 竖线全长，世界单位 |
| Horizontal Width | 0.026 | 横线亮芯宽度 |
| Vertical Width | 0.032 | 竖线亮芯宽度 |
| Glow Width | 16 | 柔光相对亮芯的宽度 |
| End Fade | 0.45 | 每条半轴末端 45% 的区域逐渐淡出 |
| Expand Time | 0.16 秒 | 从交点向两边展开 |
| Hold Time | 0.06 秒 | 完全展开后的停留 |
| Fade Time | 0.48 秒 | 平滑淡出 |
| Loop Interval | 0.35 秒 | 循环间隔，需开启 Loop |

Core Color / Glow Color 支持 HDR，Brightness 控制整体亮度。单次总时长默认为 0.7 秒。运行时修改参数后调用 `Play()` 重新应用；只调整颜色、亮度、亮度曲线、线宽时可调用 `RefreshAppearance()`。

## 实现与朝向

只使用 **1 个粒子系统、1 个粒子、1 个材质、1 张纯节点 Shader Graph**，亮度曲线会自动生成一张 512×1 的数值纹理，无需手工绘制贴图，也没有 Custom Function / 手写 HLSL。Shader Graph 中按输入、展开淡出、横线、竖线、颜色输出分组，可以继续编辑。

粒子流为 Position、Normal、Color、UV、AgePercent；AgePercent 打包到 UV0.z，驱动 Shader Graph 展开和淡出，因此不依赖全局 Time，也不会让不同实例串时间。

Renderer 使用 Billboard / View，**Allow Roll 保持开启**，使横线跟随相机屏幕的横轴；相机环绕、滚转和对象旋转时都维持屏幕水平。效果位置仍是场景中的世界位置，尺寸随透视距离变化；它不是固定像素大小的全屏 UI。两版均位于 CrossFlareForeground Layer 和同名 Sorting Layer，材质使用 Transparent 队列 3999，Shader Graph 深度测试设为 Always，因此显示在玩家、敌人及场景不透明物体前面，也会透过墙体可见。

材质内包含独立的程序化柔光，不开启 Bloom 也可见；开启 Bloom 后会额外泛光。控制器通过 MaterialPropertyBlock 调整每个实例，不修改共享材质。

预制体本身默认单次播放，预览场景的实例开启循环。控制器负责统一尺寸、时间与播放；实际形状和动画由 Shader Graph 与原生粒子生命周期实现。

验证图片与动画位于项目根目录 `Artifacts/CrossFlare/`。

## 十字形状与边缘

横竖长度比例为 2:1，两条线的亮芯保持各自固定粗细，在交点直接叠加。两条光线都包含亮芯、近层柔光及宽而淡的外层光晕。末端通过透明度逐渐消失。Inspector 的“定格峰值”停在展开完成后的停留阶段。

Glow Width 调整线条两侧的柔光范围；End Fade 调整末端淡出占各半轴长度的比例，值越大，渐隐区域越长。淡出时间仍由 Fade Time 控制。

最初版本的预览保留在 `Artifacts/CrossFlare/BeforePeakOptimization/`。

## 亮度变化曲线

在 CrossFlareController 的 **Brightness Curve** 中编辑曲线：横轴是单次播放进度 0～1（不包含循环间隔），纵轴是亮度倍率。0 表示熄灭，1 保持原亮度，大于 1 增强峰值。默认由暗快速提亮，在约 26% 进度达到 1.25 倍，然后逐渐回落至 0。

最终亮度由 **Brightness × Brightness Curve × 原有出入淡出** 共同决定。曲线可以有多个峰值，负值按 0 处理。空曲线按恒定 1 处理。

Shader Graph 按粒子 AgePercent 读取曲线，因此运行、循环和定格使用相同时间基准。每个实例使用独立的曲线数值纹理，播放时不会修改共享材质；纹理在禁用或销毁对象时释放。修改曲线后，Inspector 会刷新预览；运行时代码修改后调用 `RefreshAppearance()`，或调用 `Play()` 从头播放。

“定格峰值”会按曲线和出入淡出寻找最亮时刻，时间精度约为单次时长的 1/512。
