# PureFlame 纯火焰

预制体：`Assets/_Project/VFX/Effects/Prefabs/PureFlame/PureFlame.prefab`。

独立的青蓝色弧形纯火焰，由单层原生 Mesh Particle System 组成，没有刀光线、辉光层或空气折射层。继承连续火焰的整体感，并在水平径向与自身法线之间平滑摆动。默认不进行刀光式旋转。

默认一轮 1.9 秒：生长 0.55 秒、燃烧停留 0.50 秒、衰减 0.85 秒。生长曲线同时控制火焰可见高度和显现强度；衰减阶段高度收缩、火焰逐步熄灭、亮度降低至零。

将预制体拖入场景或打开 Prefab 编辑模式，在根节点 PureFlame Controller 调整三个阶段的时间、生长曲线、亮度曲线及循环开关，点击“一键应用并播放”或“循环预览（调参）”。运行时调用 `PureFlameController.Play()` / `Stop()`，也可启用自动播放。

材质位于 `Assets/_Project/VFX/Effects/Materials/PureFlame/PureFlame.mat`，可调整颜色、透明度、高度、整体感、倾角和摆动速度。Shader Graph、材质、网格及控制器独立于 Slash270，修改新效果不会改动原刀光。仅生长查找纹理使用共用的默认资源，运行时控制器创建每实例曲线纹理。

验证图位于 `Artifacts/PureFlame/`。已验证仅存在一个火焰系统，生长时亮度增加、衰减时降低、结束后完全清空；调参时粒子尺寸不会被停止预览覆盖。

底部使用随时间流动的宽幅噪声边界与柔和透明过渡，减少规则圆弧切边。材质的 `Flame Root Irregularity` 控制起伏强度，默认 0.28；增大后底边更不规则。内圈火焰已从预制体移除，保留的单层仍有完整生长、燃烧、衰减动画。
