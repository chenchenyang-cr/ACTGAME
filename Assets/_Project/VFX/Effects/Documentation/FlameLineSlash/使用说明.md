# 刀光特效：统一控制版本

使用 `Assets/_Project/VFX/Effects/Prefabs/FlameLineSlash/FlameLineSlash.prefab`，选中根节点的 **Flame Line Slash Controller**。运行时由一个控制脚本统筹六个原生粒子系统及 Shader Graph。

## 一键控制

1. 将预制体拖入场景，或双击进入 Prefab 编辑模式。
2. 在根节点调整生长、停留、消散时间，编辑生长与亮度曲线。
3. 点击 **一键应用并播放**，直接预览全部层。**停止**会清空所有粒子。
4. 修改场景实例的设置只影响该实例；需要保存为预制体默认值时，使用 Unity 的 Overrides / Apply，或在 Prefab 编辑模式保存。

仅在 Project 中选中资源时可以编辑参数，但需进入场景或 Prefab 编辑模式才能预览。运行模式由“启用时自动播放”控制，也可通过 `Play()` / `Stop()` 调用。可勾选“循环播放”。不要再用旧的单独生长面板控制时间；旧菜单现在提供跳转提示。

## 参数含义

- **生长时间**：从左向右长完整条刀光的秒数，默认 0.15。
- **停留时间**：长完后保持的秒数，默认 0.25。
- **消散时间**：线条溶解、火焰熄灭和消散粒子所在阶段的秒数，默认 0.6。
- **总时长**：三段相加，默认 1 秒。亮芯、火焰、两层光晕与伴随粒子的时序自动同步。
- **生长进度曲线**：横轴 0～1 表示生长时间比例，纵轴 0～1 表示已生长长度；斜率即速度。需从 (0,0) 到 (1,1) 单调上升。
- **亮度变化曲线**：横轴覆盖整个效果的总时长；纵轴 1 表示原材质亮度、0 表示熄灭、大于 1 表示增强。统一影响所有光晕、火焰、亮芯及粒子。
- **整体亮度倍率**：在曲线结果上再乘一个倍率，不改变原材质色相或透明度。

调整参数后点击应用或重播。控制器采用每实例曲线纹理与 MaterialPropertyBlock，不改共享材质，因此多个实例可使用不同时间、曲线与亮度。停止时保留 GameObject，所有粒子清空；禁用或销毁会释放临时曲线纹理并还原属性覆盖。

## 外观调整

- `03_WorldUpFlame.mat` 的 **Flame Opacity** 调整火焰透明度，当前 0.32；**Flame Height (Shape Mask)** 调整轮廓高度，当前 0.72。降低高度不会压缩流动纹理。
- 火焰始终沿世界 +Y 燃烧，靠两端更低、更淡；仍是一整张连续火焰带。
- 亮芯中心宽度 0.16，近层光晕 1.05，外围柔光 2.4。颜色分别由对应材质调节。
- `04_GrowthParticles` 为一个生长发射器，`05_DissolveParticles` 为一个消散发射器。前端随曲线移动，原生发射积分存在帧级误差。
- 伴随粒子是细短淡紫光屑。大小、运动范围可在粒子系统中调整；控制器保留伴随粒子原有的寿命、发射数量与速率，只在播放期间重映射发射时间和前端移动速度；停止后恢复原始模块配置。

## 实现与验证

`Assets/_Project/VFX/Effects/Scripts/FlameLineSlash/FlameLineSlashController.cs` 是唯一运行控制组件；`Assets/Editor/FlameLineSlash/FlameLineSlashControllerEditor.cs` 提供中文 Inspector 与编辑器预览。仍使用 Shader Graph 实现形状、火焰和溶解，没有自定义 HLSL、独立 MeshRenderer 或 VFX Graph。

`Artifacts/FlameLineSlash/controller_validation.txt` 记录时间同步、亮度倍率、多实例隔离、播放循环、停止及短寿命清理测试；该目录同时保存实际渲染预览。`AgentScripts/` 下的脚本仅用于资源制作与验证，不参与游戏构建。

控制器修复：HDR 颜色使用原始向量传递，避免额外的色彩空间转换；独立应用参数不会把原生粒子预览锁成零亮度。停止预览会恢复粒子模块与原有渲染属性。

## 调色与预览

亮度控制已改为 Shader Graph 内独立的 `_ControllerBrightness` 倍率，控制器不再覆盖材质 `_Tint`、`_RootTint` 或 `_Opacity`。停止会清除该特效的临时渲染覆盖，防止遗留黑色。

在根节点点击 **循环预览（调参）**，即可切换到材质持续调整；或者点击 **定格预览（调色）**，停留在燃烧阶段观察颜色与透明度。切换 Inspector 不会停止预览。这两个按钮不会修改你保存的循环设置或其他外观参数。
