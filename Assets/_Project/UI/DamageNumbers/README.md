# 伤害跳字

选择 `Profiles/DefaultDamageNumber.asset` 调整默认跳字。Inspector 下方的预览区显示实际 TMP 文字，可播放、重播、切换随机种子和拖动时间；模拟伤害、暴击和循环设置位于参数列表末尾。

## 接入

- `DamageNumberManager` 订阅 `CombatHitEventBus.HitConfirmed`，只显示敌人受到的正伤害以及普通/暴击结果。数值来自 `CombatHitResolution.Damage`（实际扣血量）。
- `Resources/DamageNumberCanvas.prefab` 在运行时自动加载；场景已有启用的管理器时使用该管理器。默认 Canvas 为 Screen Space Overlay，参考分辨率 1920×1080，预热 16 个数字，最多同时显示 128 个；达到上限时回收最早的数字。
- `CombatHitProfile` 中的“跳字预设覆盖”为空时继承默认预设；“禁用跳字”可关闭该攻击的数字。
- 沿用 HitBox 的 Single/Repeated 命中规则，每次接受的有效伤害对应一个数字。
- 当前已有 HitProfile 的 Damage 都是 0，未改变这些数值。正式攻击要显示跳字，需在其受击配置中设置正伤害；编辑器模拟预览不依赖伤害配置。

## 参数

- 世界锚点选择命中点或敌人位置，并添加世界偏移。默认记录生成时的位置；跟随目标开启后跟随目标平移，目标销毁后保留最后位置。
- 初始 UI 偏移、随机偏移、位移幅度和抖动幅度的单位均为 Canvas 参考像素。X/Y 位移曲线横轴是生命周期 0～1，纵轴乘对应位移幅度，可分别调整侧移和上飘/回落。
- 缩放可独立设置开始延迟和持续时间；曲线横轴为缩放阶段进度 0～1，播放完保持末值。持续时间为 0 时沿用总时长。缩放曲线乘初始缩放，暴击再乘暴击倍率；只缩放文字，不放大位移或抖动距离。
- 淡出安排在总持续时间的最后一段。例如持续 0.8 秒、淡出 0.25 秒，则 0.55 秒开始淡出。淡出时间超过总时长时按整个生命周期淡出，0 表示到期直接结束。
- 自身抖动可独立设置开始延迟和持续时间；曲线横轴为抖动阶段进度 0～1，到期停止，持续时间为 0 时沿用总时长。方向支持水平、垂直、自定义角度和二维自由；0° 水平、90° 垂直。正弦频率按 Hz，柏林噪声参数表示采样速度。各阶段都随跳字总生命周期结束而回收。
- 字体粗细相对于原字体材质调整，负数变细、正数变粗、0 保持原字重。
- 发光包括字面亮度和外沿光晕，支持 HDR 颜色、强度、范围与衰减曲线；曲线横轴为总生命周期进度 0～1，纵轴乘强度，0 恢复普通文字。每个数字使用独立材质，互不影响，也不修改字体资源。
- 默认字体使用 Mobile SDF shader；启用发光时通过 `Resources/DamageNumberGlow.mat` 的完整 SDF shader 支持光晕，并保留构建所需的 GLOW_ON shader variant。
- 每个数字有独立的相位/噪声种子。默认包络在出现与结束时回到零幅度。
- 默认使用非缩放时间，不随全局慢动作变慢；角色动画顿帧不暂停跳字。
- 世界锚点在 Canvas 渲染前通过实际输出相机投影，避免 Cinemachine 更新前的旧相机姿态。相机后方、视口外或无相机时隐藏，生命周期仍正常推进。
- 小数位为 0 时向上取整，避免正伤害显示成 0；其他位数按指定精度显示。

## 文件职责

运行时代码位于 `Assets/_Project/Scripts/UI/DamageNumbers`：Profile 保存参数并采样，Manager 管理事件和对象池，View 应用文字样式及动画。Editor 下的自定义 Inspector 与运行时使用相同采样方法。

验证已覆盖独立的命中筛选、预设覆盖、各波形和方向、淡出边界、目标销毁、对象池，以及 Play 模式的真实 HitBox → 伤害接收 → 确认命中 → 数字显示/回收。具体战斗中的视觉节奏可继续在 Game 视图调整预设。
